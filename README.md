# STAROS

A web desktop OS for Hack Club Stardance.

## Demo

https://electroniccreator.github.io/staros/

## What it does

- Desktop with app icons
- About, Files, Terminal, Notes, Settings
- Car wallpapers (`car1.jpg`, `car2.jpg`, `car3.jpg`)
- See-through windows
- Also includes a tiny bootable assembly kernel (`boot.asm`, `kernel.asm`)

## How to run

Open the demo link, or download the repo and open `index.html` in a browser.
